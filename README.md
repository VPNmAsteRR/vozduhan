# Воздухан

**Браузерная мини-игра для Яндекс Игр.** Ты сидишь в кафе, а собеседник рассказывает про свою рыбалку. Терпение тает, подозрение растёт — нужно вежливо сбежать.

## Как играть

Собеседник говорит без остановки. В его монологе появляются «крючки» — вопросы и паузы. Отвечай вовремя и правильно, чтобы поднять побег, но не переборщить с подозрением: если оно дойдёт до предела, побег провален.

- **1–4** — кивнуть, удивиться, посмеяться, посочувствовать
- **Пробел** — попросить отмазку во время вдоха собеседника, **1–3** — выбрать вариант
- **Q / W / E** — наушник, фейковый звонок, кофе
- **P** или **Esc** — пауза
- На сенсорном экране — крупные кнопки внизу

Побег = 100%. Терпение = 0 — тоже конец.

## Что внутри

| | |
|---|---|
| **15 уровней** | кафе, вечеринка, свадьба, лифт, ночной поезд, библиотека, автобус, парикмахерская, офис, рынок, музей, аэропорт, парк, кинотеатр, мастерская |
| **Бесконечный режим** | открывается после 15-го уровня, сложность растёт |
| **Босс-фазы** | отдельный ритм крючков и ускоренная потеря терпения |
| **Контент** | у каждой локации свои темы, монологи и десятки вариантов крючков |
| **Звук** | синтез через WebAudio, без аудиофайлов |
| **Сохранения** | рекорд, звёзды, открытые уровни — в `localStorage` |
| **Яндекс Игры** | SDK подключается по `/sdk.js`, отправляет события старта и остановки |

## Запуск

Сервер и сборка не нужны:

```bash
# просто открыть файл
xdg-open index.html      # Linux
open index.html          # macOS

# или поднять локальный сервер
python3 -m http.server 8080
```

Полезные параметры в адресе:

```
index.html?seed=123    воспроизводимый забег
index.html?debug=1     отладка, клавиши 7/8/9 ставят параметры на 100
```

В режиме `file://` SDK Яндекса не грузится — игра остаётся автономной.

## Структура

```
index.html          экраны интерфейса и подключение скриптов
css/style.css       адаптивная вёрстка, сцены, анимации
js/data.js          локации, реплики, CONFIG (баланс)
js/rng.js           генератор случайных чисел с seed
js/audio.js         синтез звуков на WebAudio
js/game.js          логика игры и сохранения
js/ui.js            DOM, рендеринг, ввод
js/yandex.js        интеграция с SDK Яндекс Игр
js/main.js          игровой цикл и автопауза
```

## Баланс

Все параметры — в объекте `CONFIG` в `js/data.js`. Быстрые ручки:

- **проще:** уменьшить `patienceDrain`, увеличить `hookWindow`, поднять `excuseEscapeBase`
- **сложнее:** увеличить `levelDrainMultiplier`, уменьшить `hookWindowMin`, снизить `escapeTarget`
- **лифт:** `elevatorRestEvery`, `elevatorRestDuration`
- **босс:** `bossPhaseDuration`
